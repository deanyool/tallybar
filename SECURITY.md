# Security

TallyBar makes no network connections. Your data is one JSON file in
`~/Library/Application Support/TallyBar/`, readable by your user account only.

## Reporting a problem

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/deanyool/tallybar/security/advisories/new)
rather than a public issue. Include the version (`TallyBar.app/Contents/MacOS/TallyBar --version`),
your macOS version and the steps to reproduce. Expect a first reply within a week.

## Supported versions

Only the latest release gets fixes.
